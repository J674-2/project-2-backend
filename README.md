# Portfolio Project 2

- This is a full stack project. You can visit the web app at 'https://portfolio-project-pi-rouge.vercel.app'. 
- See 'https://github.com/J674-2/project-2-frontend.git' for the frontend of this project.

## Focus
- Deployment and connection of a frontend (TypeScript) and a backend (Python).
- Connection to a PostgreSQL database. 
- Responsive design.
- User input and interactions.
- Test-driven development.
- App design & user journey creation on Figma.

## Deployment
- Frontend - Vercel
- Backend - AWS

## Libraries & Frameworks 
### Frontend:
- Vite
- React
- Declarative React Router
- Tailwind CSS
- Tanstack Query
- Vitest
- React Testing Library
- Mock Service Worker
- Playwright

### Backend:
- Django
- Django Rest Framework
- django-cors-headers
